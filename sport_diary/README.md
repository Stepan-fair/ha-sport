# Спорт для Home Assistant OS
Основной способ установки после публикации — добавить URL репозитория в магазин приложений HA и выбрать «Спорт». Для локальной разработки можно скопировать каталог приложения в /addons/sport и обновить список локальных приложений. Выберите постоянный источник перед началом ведения дневника. В конфигурации укажите entity_id весов для person1_weight и person2_weight. Вход через существующий HA Ingress. Укажите разные ID пользователей HA в `person1_user` и `person2_user`. При включённой опции `person1_can_open_both` первый пользователь может переключаться между обоими дневниками. Второй открывает только свой дневник.

Данные находятся в /data/sport.db внутри дополнения. Черновик хранится в localStorage телефона отдельно для каждого профиля. При конфликте сохранения обновите страницу и повторите. «Найти» ищет продукты по названию или штрихкоду на вашем HA. Для первого наполнения расширенного каталога нужен доступ к GitHub. Дополнительный поиск в Open Food Facts доступен по кнопке. Камера для штрихкода требует поддержки BarcodeDetector браузером, ввод цифр доступен всегда.

Весы опрашиваются в фоне. HA и ручные замеры сохраняются с временем события. Для прошлой тренировки берётся последнее известное измерение на момент начала, для сохранённой тренировки хранится снимок. Оценка энергии использует длительность силовой части с паузами и вес, плюс показания дорожки или оценку при их отсутствии. Суточная оценка автоматически складывает расход обычного дня по профилю и добавку за записанные занятия. В настройках профиля под каждым упражнением каталога доступны фото и техника. Вне домашней сети требуется работающий внешний вход в HA.

Локальная проверка в Windows из sport: установите SPORT_BIND=127.0.0.1, SPORT_DATA на пустой тестовый каталог и выполните python server.py. Адрес http://127.0.0.1:8099/. Команды проверок: python -m unittest test_sport и node --test logic.test.js session.test.js.
