# Спортивный дневник для Home Assistant OS

Семейный дневник тренировок, питания и добавок. Этот репозиторий предназначен для установки через магазин приложений Home Assistant. Версия 0.5.1 — кандидат для проверки на тестовых данных.

## Установка

В Home Assistant откройте **Настройки → Приложения → Установить приложение → ⋮ → Репозитории**. Вставьте URL этого Git-репозитория, добавьте его и откройте «Спорт». После установки укажите ID разрешённых пользователей HA, имена профилей и датчики веса в конфигурации, запустите приложение, откройте веб-интерфейс. Инструкция и ограничения приведены в [DOCS.md](sport_diary/DOCS.md).

## Разработка и обновления

Исходники приложения находятся в `sport_diary/`. Основная ветка содержит согласованные версии. Для обновления измените исходники, увеличьте `version` в `config.yaml`, опишите изменения в `CHANGELOG.md` и проверьте сборку. После слияния в основную ветку создайте тег с тем же номером. Пользователь открывает обновление в HA и проверяет его описание. При необходимости обновите список репозиториев в магазине.

Из одной установки в следующую сохраняйте адрес репозитория, ветку установки и slug. Данные пользователя находятся в приватном каталоге приложения. Перед обновлением с миграцией создайте резервную копию HA с этим приложением. Для отката версии со сменой схемы восстановите совместимую резервную копию.

Проверки из корня репозитория:

```sh
python -m unittest discover -s sport_diary -p test_sport.py
node --test sport_diary/logic.test.js sport_diary/session.test.js
python sport_diary/package.py
```

Сценарии Edge для Windows находятся в `sport_diary/browser_check.py`. Рабочее подключение к HA, iPhone, восстановление резервной копии и обновление поверх предыдущей версии проверяются отдельно от CI.
